# CCST Cybersecurity — Guía de estudio (PDF)

Guía de práctica con 21 preguntas situacionales, respuestas y explicaciones para el examen **CCST Cybersecurity**.

## Archivo

- [`CCST-Cybersecurity-Guia-Estudio.pdf`](./CCST-Cybersecurity-Guia-Estudio.pdf)

## Regenerar el PDF

```bash
pip install fpdf2
python3 docs/ccst-cybersecurity/generar_guia_pdf.py
```

Requiere las tipografías Noto Sans / Noto Serif en el sistema (`/usr/share/fonts/truetype/noto/`).

## Aviso

Material de práctica elaborado a partir de introducciones parciales. No es un banco oficial de preguntas de Cisco.
